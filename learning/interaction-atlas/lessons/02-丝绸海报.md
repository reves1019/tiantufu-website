# 02 · 丝绸海报：把位置转换成角度

目标：海报根据指针位置轻微转动，离开后回正；手机和键盘仍可触发查看动作。

阅读 [PosterExample](../../../src/recipes/interaction-atlas/examples/PosterExample.tsx) 和 [SilkPoster](../../../src/recipes/interaction-atlas/SilkPoster.tsx)，随后在 [styles.css](../../../src/recipes/interaction-atlas/styles.css) 中搜索 atlas-poster、atlas-fabric。

## 提炼出的核心

```text
x = (clientX - left) / width - 0.5
y = (clientY - top) / height - 0.5
rotateX = -9 × y
rotateY =  9 × x
```

坐标除以宽高后，卡片中心是 0，两端约为 ±0.5。这里的 9 是全区间，单侧约 4.5°。先加 perspective，再绕两轴转动，形成空间感。

指针坐标不出现在 UI 文本中，因此不需要用 state 保存每次移动。组件直接写 --tilt-x/--tilt-y；CSS 使用它们绘制变换。pointerleave 将变量归零。

丝绸“质感”由重复径向纹理、锥形渐变和缓慢旋转叠加而成，不是布料仿真。展示层与按钮独立，触摸设备不需要模拟 hover。

## 动手练习

1. 将代码中的角度乘数从 9 改为 5，比较卡片边缘移动幅度；改回时不需要动 CSS。
2. 开启减少动态，检查 computed transform 为 none，再用 Tab/Enter 触发查看按钮：示例的 onOpen 次数仍增加。
3. 修改 item.color，观察纹理保留而材质色调改变。
4. 移到卡片四角再离开，观察是否总能回正。

答案提示：减少动态需要 JS 判断与 CSS 回退两层一致；只停止鼠标事件不会撤销已绘制的 transform。独立页面通过 html[data-motion] 同步两层。

## 自检

中心接近水平、边缘倾斜有限、离开复位；没有鼠标也能按按钮；图像使用 contain 保留完整比例。不要在每次 pointermove 中设置整棵页面的 React 状态，也不要将装饰动画当作“查看作品”的唯一入口。
