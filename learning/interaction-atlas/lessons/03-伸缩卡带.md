# 03 · 伸缩卡带：预览与选择分离

目标：鼠标经过时临时展开，点击后固定当前选择。手机通过点击和横向滚动浏览。

阅读 [StripExample](../../../src/recipes/interaction-atlas/examples/StripExample.tsx) 与 [ExpandingStrip](../../../src/recipes/interaction-atlas/ExpandingStrip.tsx)。

## 提炼出的核心

| 事件 | hovered | selected | 展开的卡片 |
| --- | --- | --- | --- |
| 初始 | null | 第一项 | 第一项 |
| 鼠标进入另一项 | 该项 id | 保持原值 | hovered |
| 点击该项 | 清空 | 请求选择该项 | 新 selected |
| 离开卡带 | null | 保持 | selected |
| 键盘选择 | 清空 | 请求目标项 | 新 selected |

data-expanded 用来表达视觉预览，aria-pressed 只表达确认的选择。这两个属性不必始终相同。hovered 指向已删除的条目时也回退 selected。

桌面通过 flex 从 1 增大到 4，其他卡片让出空间。手机改成固定基准宽度（折叠 95px，展开 255px）与 overflow-x:auto，避免把每张卡片挤成无法点击的细条。

## 动手练习

1. 悬停第二项，观察它展开而“已确认”状态保持第一项。
2. 点击第二项并移开鼠标，它应保持展开。
3. 点击之后按 Home，确认鼠标预览不会盖住键盘的新选择。
4. 把桌面展开倍率改为 3，比较可读空间；在手机宽度再次检查，不要只看桌面。

答案提示：不应在 pointerenter 中调用 onChange。临时预览若写入父级，会使滑过多张卡片变成多次真实选择。

## 自检与取舍

鼠标、点击与键盘语义一致；手机可以横向浏览；删项后不留下无效预览；减少动态后空间立即调整。这里的 flex 动画会触发布局，是少量卡片展示的主动取舍，不要将它推广为大量条目的高性能方案。
