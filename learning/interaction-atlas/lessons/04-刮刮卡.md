# 04 · 刮刮卡：擦除覆盖层

目标：拖动擦除金色覆盖层，达到面积阈值后揭晓；键盘用户可直接揭晓；重置可恢复。

阅读 [ScratchExample](../../../src/recipes/interaction-atlas/examples/ScratchExample.tsx)、[ScratchCard](../../../src/recipes/interaction-atlas/ScratchCard.tsx) 和 [model.ts](../../../src/recipes/interaction-atlas/model.ts) 的 canvasPoint/erasedFraction。

## 三个层次

1. 底层是真实 img，完整比例显示，不参与画布擦除。
2. 上层 canvas 先绘制不透明金色渐变与斜线。
3. 指针画笔用 destination-out 擦掉上层像素，使下层逐渐可见。

画布内部尺寸是 480×640，CSS 显示尺寸可以更小。坐标必须先转换：

```text
canvasX = (clientX - left) / displayWidth × 480
canvasY = (clientY - top)  / displayHeight × 640
```

直接用 clientX/Y 会受页面位置和缩放影响。画笔半径 30 个画布像素，因此在半尺寸显示时可见半径约为 15 CSS 像素。

pointerdown 捕获指针，拖到元素边缘外仍能收到后续事件。连接相邻采样点避免快速移动留下空隙；单独画一个圆让点击也有痕迹。pointerup/cancel 结束笔画并释放捕获。

只在手势结束时遍历 RGBA 的 alpha：小于 128 视为已擦除。透明像素占比达到 threshold 即揭晓，默认 .45。统计频率低于每次移动扫描，且底图没有进入 canvas，不会因底图跨域而污染这个画布。

## 状态与复位

```text
覆盖 → 拖动擦除 → 达到阈值 / 直接揭晓 → revealed
revealed → 重新覆盖 → generation + 1 → 重新绘制覆盖层
```

revealed 控制可见状态和辅助信息；ref 中的 revealedOnce 防止同一周期重复调用 onReveal。换图使用 key={item.id} 重建全部内部状态。只改 item 属性而不改 key，不是本组件约定的换图复位方式。

## 动手练习

1. 把阈值调到 10%，划几笔后松手，比较 90% 所需面积。
2. 不使用指针，Tab 到“直接揭晓”，按 Enter，再按“重新覆盖”。
3. 揭晓后点击“换一张练习图”，覆盖层应重新出现，而累计次数保持。
4. 在 320px 宽度下擦中央位置，痕迹应跟随手指。

答案提示：缩放误差检查 canvasPoint；重置无效检查 generation；换图不复位检查 key。该效果不是隐藏秘密的安全机制，因为底图已经下载到浏览器。

## 自检

鼠标/触摸有真实擦除痕迹；阈值和直接揭晓都会通知一次；再次覆盖能重新揭晓；减少动态下内容立即显示。画布使用 touch-action:none 仅拦截其内部手势，其他区域仍应能滚动。
