# 06 · 流式轮播：多种输入，共用一次选择

目标：点击卡片、上一张/下一张、方向键和横滑都能选择作品；查看原图由调用方接管。

阅读 [FlowExample](../../../src/recipes/interaction-atlas/examples/FlowExample.tsx)、[ImageFlow](../../../src/recipes/interaction-atlas/ImageFlow.tsx) 与 [model.ts](../../../src/recipes/interaction-atlas/model.ts) 的 swipeStep/wrapIndex。

## 提炼出的核心

```text
点击卡片 / Home / End → choose(id)
上一张 / 下一张      → wrapIndex(index ± 1) → choose(id)
横滑                 → swipeStep(start, end) → ±1 → 同一个 step
```

环绕索引写成 ((index % length) + length) % length，处理 JavaScript 负余数。空列表返回 -1，不允许取不存在的 item；此时前后按钮禁用。

滑动必须同时满足：水平距离大于 45px，且大于垂直距离。向左滑为下一张，向右为上一张。短按、纵向滚动、正好 45px 或两方向距离相同均不切换。

容器 touch-action:pan-y 保留纵向滚动。pointercancel 清除未完成手势。一次横滑结束后，浏览器可能继续生成 click；moved ref 用来吞掉这次点击，避免刚选中的图又被松手位置的卡片覆盖。键盘合成 click 的 detail 为 0，仍可正常使用。

## 视觉与语义

选中卡片通过 flex 获得更多空间，aria-pressed 宣告当前项；底部 aria-live 文本宣布“序号 / 总数 · 标题”。没有自动播放，因此用户能按自己的节奏阅读。

onOpen(selected.id) 只表达打开请求。原图按钮与卡片按钮是平级，不嵌套 button。社团文化页将该回调接到现有高清阅读器；教学例只显示收到的 id。

## 动手练习

1. 在最后一张点“下一张”，应回第一张；第一张点“上一张”，应回最后一张。
2. 用手机横滑切图，再纵向滑动页面，纵滑不能误切图。
3. 点击“记录打开请求”，观察 onOpen 与当前选择一致。
4. 清空列表，确认两个箭头被禁用；恢复后可以重新切换。

答案提示：边界错误检查 wrapIndex；横滑后跳回检查合成 click；纵滑被吞检查 touch-action 和 dx/dy 的比较。大量数据应先限制可见项，不能直接让上百张图片同时参与 flex 动画。

## 自检

三种输入获得相同结果；空数据不报错；取消手势不改变选择；减少动态后直接切换而不丢内容；打开动作收到稳定作品 id。
