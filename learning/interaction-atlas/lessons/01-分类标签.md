# 01 · 分类标签：状态先于动效

目标：切换分类时，内容、颜色、焦点和辅助信息一起更新。只改变背景颜色不能完成这个交互。

## 阅读顺序

先看 [TabsExample](../../../src/recipes/interaction-atlas/examples/TabsExample.tsx)，再看 [useSelection](../../../src/recipes/interaction-atlas/useSelection.ts) 与 [ShaderTabs](../../../src/recipes/interaction-atlas/ShaderTabs.tsx)。

数据流是 `点击 / 方向键 → choose(id) → 父级或本地 value → selected → 面板`。selected 从 items 与 value 派生，没有另存一份“当前卡片”，避免数据更新时两份状态不同步。

## 提炼出的核心

```tsx
const selected = items.find(item => item.id === (value ?? local)) ?? items[0]
```

value 没有传入时读 local；当前项消失时回退第一项。choose 在非受控模式更新 local，然后通知 onChange。受控模式只发通知，父组件有权拒绝。

标签使用 role=tab、aria-selected、aria-controls；面板用 aria-labelledby 指回当前标签。useId 让同页多个实例不会产生重复 DOM id。只有当前标签 tabIndex=0，方向键/Home/End 负责组内移动；Tab 可以离开标签组。

色彩写入 CSS 变量 --atlas-tint。背景是不会被屏幕阅读器读取的渐变装饰层。减少动态后只是纹理停止，选择本身依然可用。

## 动手练习

1. 在练习页勾“锁定父级选择”，点击第二项：最近 onChange 变了，但高亮仍是第一项。
2. 取消锁定，用 End 选择最后一项，再点“移除末项”：面板回退第一项；父级 value 的状态栏仍显示原 id，说明回退没有偷偷写数据。
3. 把示例改成不传 value 与 onChange，观察它仍能选择；这是组件自己的状态。
4. 尝试 panelContent 放一段较长正文，在 320px 下确认内容完整显示。

答案提示：受控选择同步多个区域时，由父级共用一个 state；正文面板使用自然高度，图片面板才使用固定展示高度。

## 自检

点击、左右键、Home/End 能更新内容；空列表显示“暂无地图”；减少动态下仍可切换；锁定父级时不擅自更改选中项。不要把颜色作为唯一选中标记，也不要用数组索引当作品的持久 id。
