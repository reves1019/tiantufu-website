# 交互图鉴实验室

通过 `/#lab` 访问，页面按需加载，未添加主导航入口。使用当前公开作品目录，保留真实作者和图片比例；不写入账号、点赞、云端或作品数据。

从 `src/components/lab/AtlasInteractions.tsx` 导入六个组件，自带隔离样式，无新增依赖。该路径现在是兼容出口，唯一实现位于 `src/recipes/interaction-atlas`。

学习与复用请从 [交互代码学习库](../learning/interaction-atlas/README.md) 开始：六篇讲解、六份可运行示例、带注释源码、独立练习页和迁移指南。网站作品演示仍在 `/#lab`，学习示例在 `/learning/interaction-atlas/index.html`。

- `ShaderTabs`、`ExpandingStrip`、`ImageFlow`：传入 `items: AtlasCard[]`，可选受控 `value`、`onChange(id)`、`label`。每张卡使用唯一 `id`，必填 `title/image/alt`，可选 `author/description/color`。
- `ShaderTabs.panelContent` 可嵌入自定义可编辑正文；赛事页用于历届资料，与作品及获奖名单共用筛选状态，保留原始编辑索引。
- `ImageFlow.onOpen(id)` 与 `openLabel` 提供独立原图入口；社团文化页用它替换原装饰图片，沿用公开目录及高清阅读器。
- `SilkPoster`：传入 `item`，可选 `eyebrow`、`onOpen()`。
- `ScratchCard`：传入 `item`，可选 `threshold`（默认 45%）、`onReveal()`。更换作品时使用 `key={item.id}` 以复位覆盖层。
- `ReactionBar`：传入 `items: Reaction[]`（`id/label/symbol/color?`），可选受控 `value: string | null` 和 `onChange(id | null)`。选择同一反应可取消。

空列表显示空态或空容器，选择列表删除当前条目后回退至首条。系统减少动态效果和站内减少动态设置均禁用材质动画、倾斜和过渡。

测试：先启动本地 Vite，运行 `node tests/lab.browser.mjs`，或运行 `pnpm test` 自动启动测试站点并执行完整回归。实验室测试在隔离浏览器验证六个组件、键盘、实际鼠标刮卡、触摸刮卡/滑动、三种宽度、减少动态和路由返回。
