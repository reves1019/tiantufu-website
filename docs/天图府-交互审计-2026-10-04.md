# 天图府全站交互审计（2026-10-04）

## 审计范围

基于仓库当前 HEAD（React 18 + TypeScript + Vite + GSAP + Three.js + Tailwind），检查 `AppShell`、导航、页面叠层、搜索、地图阅读器、作品卡、成员展架、弹窗、移动端入口，以及 `DESIGN.md`、`PRODUCT.md`、`docs/修缮清单.md` 和现有回归测试。

参考交互来源：UI Layouts Image Accordion 及其组件分类：Visual Effects、Animation & Motion、Overlays、Forms、3D & Visuals、Layout、Cards、Media & Galleries、Navigation、Disclosure、Code。

## 已有优势

- 已有完整的页面叠层路由、站内搜索、快捷键、移动导航、焦点恢复与多个弹窗焦点循环。
- 地图阅读器已有缩放、双击、滚轮、键盘方向键、拖动、惯性、缩略窗、图片失败状态和减少动态回退。
- `AccordionGallery` 已有桌面 hover/focus 展开、键盘方向键/Home/End、移动端横向吸附的基础。
- 作品卡、文件夹卡、关键词、光斑、Image Trail、Circular Gallery、ScrollProgress 和 FlowButton 已形成统一的朱红/暖纸/深墨交互语言。
- 设计文档已明确优先 transform/opacity、焦点管理和 prefers-reduced-motion。

## 当前主要缺口

### P0：全站状态和可访问性一致性

- 建立统一的交互状态模型：idle、hover、focus、pressed、selected、loading、success、error、disabled。
- 所有可点击图片卡改为明确的 button/link 语义，避免依赖 `div[role=button]`。
- 图片加载失败、搜索无结果、地图数据缺失、管理员保存失败需要统一可恢复反馈。
- 把弹窗、抽屉、搜索、移动菜单统一为同一套焦点捕获/返回、背景 inert、Esc、点击外部策略。
- 折叠内容统一 `aria-expanded`、`aria-controls`、隐藏节点 `inert`。

### P1：导航和页面转场

- 页面切换提供可感知但可中断的方向性转场，快速连续点击只保留最后目标。
- 深层页建立稳定 URL ID，而不是依赖数组索引，保证刷新、前进后退和分享链接稳定。
- 移动导航打开时锁定背景滚动，导航完成后恢复触发按钮焦点。
- 增加“当前位置/阅读进度/返回上层”的统一提示。

### P1：作品与地图交互

- 将 Image Accordion 扩展为可点击/触摸明确选中状态，不依赖 hover；桌面使用宽度展开，移动端使用横向 snap。
- 作品卡支持收藏/复制链接/分享反馈时只在已有产品需求允许的范围内实现；先做可见的“已打开、正在加载、加载失败、已复制”反馈。
- 地图阅读器增加拖动边界提示、缩放状态说明和触摸手势提示；保留现有 minimap。
- 画廊加入预加载相邻图片，失败时保留标题、作者和重新加载按钮。

### P1：输入、搜索和内容发现

- 搜索加入最近搜索、类型筛选、快捷清空、结果计数和空状态操作建议。
- 筛选 chips 与 URL 状态同步，刷新/返回可恢复。
- 表单和管理员编辑增加脏状态、保存中、成功、失败、重试和离开确认。

### P2：动效和视觉工具

- 只为有信息价值的地方添加 Image Reveal、Spotlight、磁性按钮、轻微视差、滚动分段和遮罩过渡；禁止同时叠加多个追踪指针 canvas。
- 所有新增动效遵循 120–200ms 微反馈、200–400ms 组件进入、300–600ms 页面转场，`prefers-reduced-motion` 下变为即时状态。
- 图片使用 `object-position` 保证地图主体不被裁切；装饰图失败不得阻塞主要内容。

### P2：性能与稳定性

- 指针追踪和滚动只使用 rAF/CSS 变量，避免每帧 React setState。
- 画廊图片懒加载并预加载邻近项；大地图保持主图清晰、缩略图轻量。
- 为长页面和 390/768/1024/1440 宽度建立统一回归矩阵；记录真实错误，不宣称未测量的帧率。

## 建议实施顺序

1. 状态/焦点/错误反馈基座。
2. 导航 URL 稳定性和转场。
3. 作品展架、Image Accordion、Lightbox 触摸和加载体验。
4. 搜索、筛选、表单状态。
5. 视觉动效增强和性能回归。

## 验收矩阵

- 桌面：鼠标 hover、键盘 Tab/Enter/Space/方向键/Home/End、Esc、前进后退。
- 移动：触摸展开、横向 snap、拖动地图、双指缩放、菜单背景锁定。
- 动效：系统 reduced motion + 应用内减少动效开关。
- 异常：图片 404、空结果、保存失败、快速重复点击、网络慢、刷新深层 URL。
- 质量：lint、tsc、build、现有回归测试、无横向溢出、无控制台错误。
