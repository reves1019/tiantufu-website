## 本轮发现并修复

1. 开始时当前工作树缺少 tsconfig、原组件与素材，基线 build 报 TS5083。只补缺失 154 文件，来源为本机 release/original 备份及原 dist 字节，未覆盖现存文件；逐文件来源/hash记录在 `.local-server/recovery-20261105.json`。原有 ReviewMarquee 兼容 EditableText 的 ReactNode 类型。
2. public 16项媒体与旧生产构建 SHA-256 一致，40处静态媒体引用均存在；没有用新图替代作者作品。详情 `.local-server/public-recovery-audit-20261105.json`。
3. 旧图鉴触摸测试在协议结束后立即断言，出现渲染时序失败。改为确认真实触摸命中/起落/位移后等待同一选中结果；保留原断言。未改图册生产逻辑，定向重复及最终完整回归通过。第一次失败日志予以保留。
4. 新增组件已修复负时长/非有限数参数回退、离场层 inert、主构建缺学习入口，以及组件预览的CSS覆盖；来源关联收紧为实际已核查的模式。
