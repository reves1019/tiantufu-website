# 网站制作端动效库 Implementation Plan

> 使用当前 Codex 协作流程实施；用户已确认接到管理员工具栏。研究、基础恢复与组件可并行，集成和验收由主代理负责。

**Goal:** 从用户指定十站提炼可复用交互，做成网站制作端可预览、调参、导出并应用页面转场的素材库。

**Architecture:** 独立 React/CSS/WAAPI 动效原语 + 带十站证据的注册表 + 隐藏路由 #design-studio。页面转场经现有内容存储持久化；默认保留原转场。代码预览和源码包使用同一实现。

**Tech Stack:** 现有 React、TypeScript、Vite、原生 Web Animations API，无新增运行时依赖。

**Spec:** 当前用户目标列出的十站与确认“接到管理员工具栏”。不是复制网站品牌或整站源码。

## Global Constraints

- 所有来源实际核查；展示站以效果参考重写，具体源码许可单独记录。
- 仅补缺失基线，不覆盖现存源码/素材；不操作生产或真实账号。
- 保留 PageStack 历史、排队、离场 inert、旧JSON、减少动态及管理员写入检查。
- 网站访客只读浏览；应用设置仅管理员。预览/调参不自动改站点。
- 组件与源码导出不依赖账号、云端或外部图片。

## Review Focus

- 非法导入参数回退；旧JSON没有动效字段仍使用原400ms效果。
- 导航中快速跳转、历史返回及中途减少动态不留下不可点击层。
- 中文/emoji文字分割、计时器卸载清理。
- 触摸无悬停、键盘焦点、320px宽度。
- 导出的源码包真实能编译运行，不只是字符串看起来正确。
