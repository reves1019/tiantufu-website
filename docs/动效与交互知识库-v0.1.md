# 天图府网站动效与交互知识库 v0.1

本文件是天图府前端动效的约束、实现选择和验收记录。它服务于后续新增页面、作品卡、地图阅读器和管理员内容面板，避免每个组件各自定义一套动画规则。

## 设计约束

- 优先动画 `transform` 与 `opacity`；颜色、边框、阴影可以用于状态反馈。涉及尺寸、布局、`top/left` 的动画需要有明确理由。
- 动画必须可中断、可逆。连续点击、浏览器前进后退和快速滚动不能留下旧页面的焦点或监听器。
- `prefers-reduced-motion: reduce` 时取消位移、缩放、惯性、视差和自动滚动，保留即时状态、透明度和内容顺序。
- 可访问状态与动画同步：折叠按钮更新 `aria-expanded`，内容同步 `aria-hidden` 与 `inert`；弹窗锁定背景、捕获焦点、Esc 关闭，并把焦点还给触发控件。
- 动画时长按交互层级区分：微反馈 120–200ms，组件进入/离开 200–400ms，页面切换 300–600ms。进入使用 `cubic-bezier(.2,.8,.2,1)`，离开使用 `cubic-bezier(.4,0,1,1)`。
- 动画层不承担信息。动态文字、跑马灯、粒子和 canvas 都必须有静态可读内容或 `aria-hidden`。

## 当前实现映射

| 交互 | 当前实现 | 关键验收点 |
| --- | --- | --- |
| 页面切换 | `PageStack` 只挂载当前页和过渡中的目标页，以 `page-enter/page-leave` 做上下淡入淡出 | 快速连续跳转保留最后意图；离场层 `inert`；减弱动态时立即切换 |
| 长页显现 | `RevealObserver` 与 `useExhibitionMotion` 使用 IntersectionObserver/GSAP ScrollTrigger | root 指向页面自己的滚动容器；离场时清理 observer/trigger |
| 地图阅读 | `Lightbox` + `mapMotion`，rAF 驱动目标镜头、拖拽惯性和缩放 | 只写图片 transform；边界收束；隐藏页面停止帧循环 |
| 地图作品展架 | `AccordionGallery` 与地图缩略图轨道 | 键盘方向键/Home/End、触摸吸附、焦点居中；减弱动态时取消平滑滚动 |
| FAQ/社团文化 | 语义 button + `aria-controls`，内容区同步 `aria-hidden`/`inert` | 折叠内容不可被 Tab 访问；管理员模式仍可编辑 |
| 地图灯箱 | Portal、背景 inert、焦点循环、Esc 和焦点恢复 | 打开后焦点进入弹窗，关闭后回到原触发控件 |
| 线性内容弹窗 | `LinearModal`，Portal、滚动锁定、背景 inert、焦点循环 | 背景不会继续滚动；关闭后触发按钮恢复焦点 |
| 关键词抽屉 | `KeywordDock` 使用 transform/opacity，面板关闭时 inert | `aria-expanded` 与 `aria-controls` 同步，键盘无法进入隐藏面板 |
| 动效偏好 | `motionPreference` 统一读取系统设置，并在快捷键面板提供“减少动效”站内开关 | `html[data-motion="reduced"]` 立即压缩 CSS 动画；canvas/WebGL 通过自定义事件停止或绘制静态帧 |

## 代码约定

```css
/* 推荐：只声明确实变化的属性 */
transition: transform 360ms cubic-bezier(.2,.8,.2,1), opacity 260ms ease;

/* 减弱动态时必须提供即时回退 */
@media (prefers-reduced-motion: reduce) {
  .motion-target { transition: none; animation: none; transform: none; }
}
```

简单悬停使用 CSS；需要拖拽、惯性或地图镜头的组件使用 `requestAnimationFrame`，并在 `visibilitychange`、卸载和 reduced-motion 变化时停止或重置；多阶段编排才使用 GSAP。滚动事件使用 passive listener，写 DOM 变换通过 rAF 合并。

作品手风琴保留 `flex-basis` 动画，因为它表达“文件夹抽出”的空间关系；它是本项目中唯一明确记录的布局动画例外。新增组件不要复制这个例外，优先用绝对定位、transform 和 opacity 组合。

## 状态与键盘验收

- 折叠/展开：Enter、Space、方向键可用；`aria-expanded`、`aria-hidden`、`inert` 与可见状态一致。
- 弹窗：打开后焦点进入，Tab 在弹窗内循环，Esc 关闭，关闭后焦点回到触发按钮；背景滚动锁定且背景节点 inert。
- 页面切换：过渡期间目标页可读，旧页不可聚焦；中途再次导航最终停在最后一次目标。
- 动效偏好：按 `?` 打开快捷键面板，使用“减少动效”切换站内偏好；切换后再次导航、地图拖拽/缩放和装饰帧循环都读取同一状态。选择“恢复系统”后重新跟随 OS `prefers-reduced-motion`。
- 作品/地图：拖拽、缩放和按钮操作可逆；边界不会把图片拖出可读范围；触摸端不依赖 hover。
- 200% 缩放、390px 手机、平板宽度、键盘导航、高对比度和 `prefers-reduced-motion` 都必须保持内容可访问。
