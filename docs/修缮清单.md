# 天图府官网修缮清单

## 2026-10-02 用户验收意见

- 待专项处理：整体交互感不足，动效偏少。已有缩放、筛选和页面淡入淡出不等于形成完整的交互体验。
- 本次按用户要求先记录，不把这一问题标记为已解决。
- 后续应统一进入、悬停、滚动、选择、返回的运动语言；优先增强地图与作者的关系、地图翻阅的手感，而不是增加无关装饰。
- 专项验收：桌面指针反馈、小屏触摸替代、键盘反馈、减少动态偏好、快速连续操作与低性能设备表现。不得宣称未测量的 60fps。

## 当前阶段：主题、社团介绍与联系

- 创作主题：三座展厅入口，明确展开与进入动作；子页使用公开作品档案，而不是只读取成员代表作。
- 社团介绍：标题与长文建立阅读层次，桌面侧栏停驻，年鉴横向浏览；占位文字与统计不包装成真实事实。
- 联系：将加入、约稿、问答与版权分为明确入口，联系方式区不诱导点击尚未确认的号码或链接。
- 保留：顶部导航、页内滚动、管理员内容路径、公开与草稿边界、高清地图阅读器。
- 范围：本地修改与验收；不自动发布，不变更云端账号或真实联系方式。

## 本轮验收结果

### 首页环形地图展架（2026-10-02）

- 用户提供的 CircularGallery 接入首页“展中的山河”，使用公开馆藏真实地图，最多展示八幅；不加入示例动物，不改首页主图和其他页面架构。
- 桌面采用透视环形排列，限制图纸倾斜，保持完整比例；慢速自动旋转、悬停/聚焦暂停、手动暂停、左右按钮、拖动吸附与键盘左右翻阅。没有恢复滚轮切换页面或增加强制长滚动。
- 逐帧角度与样式写入 DOM，只有当前地图改变时更新标题状态。速度按秒计算，卸载清理动画帧与观察器；减少动态偏好关闭自动旋转、手动切换直接定位。
- 手机采用原生横向滑动与吸附，不使用压缩地图的透视效果；标题同步当前图片，隐藏原生滚动条。提示与按钮文案集中于 ui.exhibition.circularGallery，兼容既有内容导入。
- 本地实测：拖动改变角度并吸附，不误开阅读器；按钮和键盘切换正常；点击南唐展开高清阅读器并放大至 150%；390px 横向滑动后作者/标题同步，文档宽度等于视口宽度。浏览器本轮未捕获运行错误。
- lint、build、新增几何回归与既有账号/内容/图片回归通过；仍有两条原有热更新警告与主包体积警告。减少动态逻辑经代码检查，未实际切换系统偏好；未测量帧率，不宣称 60fps 达标。云端模拟测试不等于生产验收。

### 地图阅读手感与统一按键反馈（2026-10-02）

- 高清地图阅读器新增基于 `requestAnimationFrame` 的惯性拖拽：松手后按速度衰减继续阅读，边界由现有 `clampView` 收束；滚轮、按钮、键盘和双击缩放改为目标镜头缓动，保留鼠标锚点不漂移。
- 变换直接写入地图与缩略窗 DOM，React 只在缩放读数跨过阈值时更新；ResizeObserver、图片切换、指针取消和卸载均清理帧与指针集合。`prefers-reduced-motion` 下直接定位，不保留惯性。
- 缩略窗改为常驻节点并以可见性过渡显示，避免打开/关闭缩略窗造成布局跳动；展架当前地图保留原始色彩，不再额外提亮或压暗。
- FlowButton 之外的文字型动作控件复用同一套朱红墨晕反馈（径向扩散、按下缩放），筛选/关闭/头像等高频状态控件继续保持轻量，不强行套用大按钮结构。
- 新增 `tests/map-motion.regression.mjs`，验证帧率无关的惯性收束、边界和减少动态偏好回退；本地 `pnpm lint`、`pnpm build`、地图视口/地图运动/既有回归通过。
- 浏览器实测地图阅读器：点击放大后 70ms 读数约 130%，约 620ms 收束到 150%，无控制台错误；尚未对真实触摸设备和 60fps 做仪器测量，也未部署线上。
